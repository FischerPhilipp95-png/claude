# Style Guide: Wasser-Video

**Gleiches Design wie das Strom-Video** (`projects/strom-video/style_guide.md`, Referenz `refs/ref-03`):
schwarzer Grund, flache knallbunte Figuren mit Augen aus Zeichen, Ausdruckswechsel auf dem Beat,
Close-up-Zoom zu Kapitelbeginn, Titel aus orangen Konstruktionspunkten, Klammer-Zeilen für Zahlen,
Kapitel-Label oben links, Musik mit 123 BPM im Charakter der Referenz.

Hier stehen nur die **Unterschiede** fürs Wasser-Thema.

## Hauptfigur: „Tropfen“

- Statt des gelben Funkens: ein **hellblauer Wassertropfen** (`#39a8ff`) mit Augen aus Zeichen und einem kleinen weißen Glanzpunkt.
- **Im Stand:** wabbelt auf dem Beat (Squash) und verliert dabei kleine Spritzer, wie der Funke seine Funken.
- **Beim Reisen:** zieht eine **Wellen-Spur** hinter sich her statt des Zickzacks.
- Warm/kalt: Der Tropfen kann seine Farbe wechseln, **blau = kalt**, **orange = warm**.

## Farben für Flüsse (wie „Gelb = Strom“ im Strom-Video)

| Farbe | Bedeutung |
|---|---|
| Hellblau `#39a8ff` | Trinkwasser, kalt |
| Orange `#ff741c` | Warmwasser |
| Braun `#8b5e3c` | Abwasser |
| Grau `#9a9a9a` | Kanalgase / Luft |

## Stations-Figuren (jede an ihrer Form erkennbar)

| Station | Figur |
|---|---|
| Wasserwerk | blaues Gebäude mit Wellen-Zeichen |
| Brunnen | runder Schacht mit Pumpen-Pfeil |
| Wasserzähler | runde Zähler-Uhr mit Zeiger und m³-Zählwerk |
| Hauptabsperrventil | rotes Handrad mit Speichen, die Augen in der Nabe |
| Filter | durchsichtiger Becher mit Sieb-Gitter |
| Druckminderer | Manometer mit Zeiger, der von Rot zurück in Grün geht |
| Warmwasserspeicher | hoher runder Tank, oben orange, unten blau |
| Durchlauferhitzer | kleiner Kasten mit Flammen-Zickzack |
| Waschbecken | Halbschale mit Hahn, darunter zwei Eckventile |
| WC | Toilette mit Spülkasten, Deckel klappt im Takt |
| Dusche | Brausekopf mit Tropfen-Strahl |
| Siphon | gebogenes Rohr, unten mit Sperrwasser gefüllt |
| Lüftung über Dach | Rohr, das oben aus dem Dach schaut |
| Kanal / Kläranlage | großes Rohr unter der Straße / runde Becken |
| Reinigungsöffnung | Rohr mit Deckel-Kappe |

Alle Figuren nutzen dieselben Palettenfarben wie im Strom-Video (Lila, Orange, Grün, Blau, Dunkelgrau, Hellgrau).

## Sound

Gleicher Charakter wie im Strom-Video (123 BPM, bassig, Glitch-Klicks, Blips, Pausen bei Kapiteltiteln).
Zur Abwechslung in einer anderen Tonart, dazu zusätzliche „Blubb“-Blips (kurzer Pitch-Anstieg) passend zum Wasser.
