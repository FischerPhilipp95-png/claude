## Die Kernaussage

Eine Klimaanlage **erzeugt keine Kälte**. Sie **trägt Wärme von drinnen nach draußen**.
Das Kältemittel macht das in einem Kreislauf aus vier Schritten: Verdampfen, Verdichten, Verflüssigen, Entspannen.
