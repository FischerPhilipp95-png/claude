# gartensaunadoktor.de

Unabhängiger Ratgeber zu Gartensauna, Außensauna und Fasssauna (Affiliate über Awin-Partnerprogramme der Sauna-Shops).
Gleiches Gerüst wie `blog/site` (handwerksdoktor.de) und `kaffee/site` (vollautomatendoktor.de): Astro, MDX-Artikel in
`src/content/artikel`, Bereiche in `src/themen.ts`, Affiliate-Links in `src/affiliate-links.ts` (Platzhalter bis zur Freischaltung).

- `npm run build`, `npm run check`, `npm run qualitaet`, `npm run rechtschreibung`, `npm run titelbilder`, `npm run pins`
- Briefing und Keyword-Liste: `sauna/briefing.md`, `sauna/keywords.csv`
- Einrichtung (Domain, Hosting, Awin): `sauna/EINRICHTUNG.md`
